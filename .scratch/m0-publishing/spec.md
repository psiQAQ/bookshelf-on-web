# M0：最小出版平台

## 目标

在首次骨架提交之后，实现可验证的本地多书出版平台及 CI 配置。依据本地规划 `.local/20261027-GPT-initial-project.md`，先出版平台，后 PDF 解析。

## 范围与验收

- 保留现有用户文件，尤其是 `books/Python for Quantum Chemistry A Full Stack Programming Guide/`；不修改、登记、暂存或发布其中材料。
- 创建两本简短原创技术示例的独立 Quarto 项目，演示公式、静态代码、章节导航、稳定锚点和浅深主题。不引用外部教材正文或封面。
- 样例默认未批准；提供与正式发布隔离的本地测试预览方式，以验证两个入口。不得为了构建成功伪造人工审核证据。
- 定义元数据、来源映射 Schema；校验 slug、路径和审核状态。明确原创样例与 PDF 来源的区别，不能虚构 PDF 哈希或页码。
- `scripts/validate.py --strict` 提供非零退出码与机器可读问题报告。非法元数据、重复 ID、不安全路径和注册了但不具备发布资格的内容应有测试。
- `scripts/build.py` 只从注册表选择明确获批的内容；空注册表也能构建门户。不扫描目录，不自动批准草稿。
- 生成门户列表；独立渲染并组装到临时目录；验证站内链接、资源和发布边界后再交付 `dist/`。失败不能留下半成品作为成功产物。
- 强制禁止出版时执行代码，确保草稿、PDF、缓存和未登记用户材料不进入最终产物。
- 固定依赖并更新 `uv.lock`；增加 PR 校验和手动触发的 Pages 工作流配置，但本任务不得实际推送或部署。核验 Quarto/Actions 版本可用性；无法验证的项如实记录。
- 实施测试覆盖资格门禁、路径边界、静态代码、空目录、多书组装与失败处理。条件允许时完成真实 Quarto HTML 渲染及链接检查。
- 项目/站点名称固定为 `bookshelf-on-web`，入口展示标题为 Bookshelf On Web。将原入口文档更名为英文 `readme.md`，新增中文 `readme_zh.md`，开头互链，范围/命令/安全说明保持一致。
- 更新双语入口文档、运行命令及已验证/未验证项目。不把本地预览等同于公开 Pages 上线。

## 非目标与权限

不安装 OCR/GPU 工具，不接入真实 PDF 转换，不实现 Pagefind 或知识图谱。不访问凭据，不改远端，不 push、不创建 PR、不部署。
本轮仅授权首次骨架提交；后续实现保留为工作区改动，未经进一步授权不 commit、合并或归档。
