# 量子化学 Python 直译：润色核对

本文件记录 `books/quantum-python-notes` 全部 17 个章节的润色阶段：谁做的、怎么做的、润色前后哪些东西被核对过。表中数字由 `.local/write_polish_review.py` 逐章比对「润色前的直译稿」（`.local/quantum-source/pre-polish/chapters/`）与仓库里的最终 `.qmd` 得到，不是手工填写的声明。

## 模型与调用方式

- 润色模型：`agy.exe`（`gemini-3.8-flash-low`，`--effort low`），系统路径 `C:\Users\ustcw\AppData\Local\agy\bin\agy.exe`。
- 调用命令：`agy -p "<润色提示词>\n\n目标文件：<相对路径>\n只改这一个文件。" --model gemini-3.8-flash-low --effort low --dangerously-skip-permissions --add-dir <仓库根>`。
- 提示词：`.local/polish_prompt.md`，其规则取自 `humanizer-zh` skill（`C:\Users\ustcw\.agents\skills\humanizer-zh\SKILL.md`）中适用于忠实翻译的子集：删填充词、打破公式化结构、变化句子节奏、信任读者、删掉总结式金句；**不采用**该 skill 中「注入个性、表达观点」的部分。
- 输入边界：润色时只提供该章的中文译文与该提示词，**不提供英文原文、也不提供对照表**，因此润色只能改措辞，无法借原文重写内容。
- 驱动脚本：`.local/polish_chapters.py`（先备份直译稿，再调用 agy 就地改写，随后调用 `.local/check_qmd.py` 比对；任一项不通过就整章回退并重试一次，最多两次）。

## 结构闸门

每章润色后必须同时满足下列条件，否则整章回退到直译稿：

1. 全部 ``` 代码块内容（围栏之间逐字符）与润色前完全相同；
2. 标题行列表（含 `{#chNN}` 锚点）逐条相同；
3. 图片行列表、图注 `**图 N.M**`/`**表 N.M**` 列表逐条相同；
4. 公式锚点行 `[]{#eq-…}` 列表逐条相同（228 张公式图一个不少）；
5. 汉字总数比例为润色前的 0.85–1.20；
6. 段落数偏差不超过 `max(3, 1%)`。
